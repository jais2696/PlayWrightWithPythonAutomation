An operator is a symbol that performs a certain operations between operands

1- Arithmatic operators : (+,-,*,/,%,**)
2- Relational / comparison operators : (==,!=,>,<,>=,<=)
3- Assignment operator (=,+=,-=,*=,/=,%=,**=)
4- Logical operator (not,and,or)


Type coversion--------

a,b = 1,2 #valid
sum = a+b

a,b = 1,"2"  #invalid
sum=a+b


Type casting----------

a,b = 1,"2"
c=int(b)
sum = a+c
