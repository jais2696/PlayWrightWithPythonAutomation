Tuples : -------
Tuples is built in data type that lets us create immutable sequences of values

tup = (87,64,33,95,76)       #tup[0],tup[1].....
tup[0]=43                    #not allowed in python
tup1 =()
tup2 = (1,)
tup3 = (1,2,3)

Tuple Methods:-------

tup = (2,1,3,1)
tup.index(el)     #returns index of firest occurrance    tup.index(1) is 1
tup.count(el)     #counts total occurrance               tup.count(1) is 2
