Dictionaries:-------------
Dictionaries are used to store data values in key:value pairs
They are unordered, mutable(changebale) & don't allow duplicate keys

dict = {
    "name" : "jyoti",
    "cgpa" : 9.6,
    "marks" :[98,97,95],
}

dict["name"],dict["cgpa"],dict["marks"]
