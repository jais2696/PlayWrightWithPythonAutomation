List in python : List is a buil-in data type that stores set of value.
it can store elements of different type (integer,float,string etc)

marks = [87,56,33,95,76]        #marks[0], marks[1]
students = ["karan",85,"Delhi"] #student[0], student[1]....
student[0]="Arjun"              #allowed in python

List slicing:-----

lis_name[starting_inx : ending_idx]    #ending index is not included
marks = [87,45,78,92,60]
marks[1:4]  is [45,78,92]
marks[ :4]  is same as marks[0:4]
marks[1: ] is same as marks[1: len(marks)]
marks[-3:-1] is [78,92]


List Methods:--------

list = [2,1,3]
list.append(4)             #adds one elements at the end [2,1,3,4]
list.sort()                #sorts in ascending order   [1,2,3]
list.sort(reverse=True)    #sorts in descending order [3,2,1]
list.reverse()             #reverses list    [3,1,2]
list.insert(idx.el)        #insert element at index

list=[2,1,3,1]
list.remove(1)             #removes first occurrance of element  [2,3,1]
list.pop[idx]              #removes element at idx
